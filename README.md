# 서비스 출시 시나리오

> 방탈출 카페를 운영하는 사장님이 되어 3주 안에 어드민, 대고객 서비스를 만들어 출시한다.
> - 먼저 사장님용 서비스(=어드민)을 만들어 전화로 예약을 받고, 사장님이 직접 어드민으로 예약을 관리한다.
>  - 어드민 출시 일정: 24.11.14
> - 이후 고객용 서비스를 만들어 고객에게 제공한다.
>  - 고객용 서비스 출시 일정: 24.11.21

# 어드민 요구사항

## 테마 

### 테마 관리 기능

- [ ] 테마를 추가할 수 있다.
  - [ ] 테마 추가 시 테마 이름, 테마 진행 시간(분), 설명, 썸네일 주소 를 입력한다.
    - **입력 필수 항목**
      - 테마 이름
      - 테마 진행 시간(분 단위)
    - 입력 선택 항목
      - 설명
      - 썸네일 주소
- [ ] 테마를 삭제할 수 있다.
  - [ ] 예약된 테마가 있다면 삭제할 수 없다.
- [ ] 전체 테마 목록을 조회할 수 있다.
  - [ ] 삭제된 테마는 조회되지 않는다.

### 테마 예약시간(타임슬롯) 관리 기능

- [ ] 타임슬롯을 추가할 수 있다.
  - [ ] 타임슬롯은 날짜, 시간 단위로 추가할 수 있다.
  - [ ] 타임슬롯 추가 시 기존 타임슬롯과 시간대가 겹칠 수 없다.
    - 예) 테마가 60분이고 15:00에 시작하는 타임슬롯이 있다면 16:00이후 부터 타임슬롯 추가 가능. 
  - [ ] 이미 예약된 타임슬롯은 예약할 수 없다.
- [ ] 타임슬롯을 삭제할 수 있다. 
  - [ ] 예약된 타임슬롯이 있을 경우 삭제할 수 없다.
- [ ] 타임슬롯을 조회할 수 있다.
  - [ ] 삭제된 타임슬롯은 조회되지 않는다.

## 예약 

### 예약 관리 기능

- [ ] 특정 테마에 대한 예약을 추가할 수 있다.
  - [ ] 테마 예약 시 테마, 타임슬롯, 예약자 이름을 필수로 입력해야한다.
  - [ ] 예약 생성 시 예약은 즉시 '확정'된다.
- [ ] 기존 예약을 취소할 수 있다.
  - [ ] 예약 시간이 지났다면 예약을 취소할 수 없다.
- [ ] 전쳬 예약을 조회할 수 있다.
  - [ ] 취소/확정 된 예약을 모두 조회할 수 있다.
